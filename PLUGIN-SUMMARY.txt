🛠️ EXTENSIBILITY (HOOKS & FILTERS)
===============================================================================

ACTION HOOKS
• gmpb_activated                      - After plugin activation
• gmpb_deactivated                    - After plugin deactivation
• gmpb_before_participant_fields      - Before form renders
• gmpb_after_participant_fields       - After form renders
• gmpb_participant_saved              - After participant data saved
• gmpb_email_sent                     - After email successfully sent
• gmpb_email_failed                   - When email sending fails

FILTER HOOKS
• gmpb_participant_fields             - Modify form field definitions
• gmpb_email_template_data            - Modify email template variables
• gmpb_form_validation_rules          - Customize validation rules
• gmpb_email_subject                  - Customize email subject
• gmpb_email_headers                  - Modify email headers
• gmpb_min_participants               - Override minimum participants
• gmpb_max_participants               - Override maximum participants

EXAMPLE USAGE

Add custom participant field:
```php
add_filter( 'gmpb_participant_fields', 'add_custom_field' );
function add_custom_field( $fields ) {
    $fields['emergency_contact'] = array(
        'label' => 'Emergency Contact',
        'required' => false,
        'type' => 'text'
    );
    return $fields;
}
```

Modify email subject:
```php
add_filter( 'gmpb_email_subject', 'custom_subject', 10, 2 );
function custom_subject( $subject, $participant ) {
    return sprintf( 'Welcome - %s', $participant['name'] );
}
```

===============================================================================
🐛 TROUBLESHOOTING
===============================================================================

ISSUE: Participant form not showing
SOLUTION:
  1. Check if product has "Enable Participant Booking" checked
  2. Verify WooCommerce is active
  3. Check browser console for JavaScript errors
  4. Clear cache (browser and WordPress)
  5. Verify assets are loading (Network tab)

ISSUE: Emails not sending
SOLUTION:
  1. Check email settings in admin (WooCommerce > Participant Booking)
  2. Verify wp_mail() is working (test with another plugin)
  3. Check spam folder
  4. Review order notes for error messages
  5. Test with SMTP plugin (WP Mail SMTP)
  6. Check server email logs

ISSUE: Validation errors on checkout
SOLUTION:
  1. Ensure all required fields filled
  2. Check email format validity
  3. Verify no duplicate emails (if setting enabled)
  4. Check JavaScript console for errors
  5. Disable other plugins for conflicts

ISSUE: Styles not loading
SOLUTION:
  1. Clear browser cache
  2. Verify file permissions (644 for files, 755 for directories)
  3. Check plugin folder exists and is readable
  4. Re-save permalinks (Settings > Permalinks)
  5. Check for CSS conflicts with theme

ISSUE: AJAX not working
SOLUTION:
  1. Check browser console for errors
  2. Verify admin-ajax.php is accessible
  3. Check nonce is being passed correctly
  4. Verify user has required capabilities
  5. Check for JavaScript conflicts

AUTOMATIC INSTALLATION (WordPress.org)
1. Log in to WordPress dashboard
2. Navigate to Plugins > Add New
3. Search for "Gym Multi-Participant Booking"
4. Click "Install Now"
5. Click "Activate"

MANUAL INSTALLATION (ZIP)
1. Download the plugin ZIP file
2. Log in to WordPress dashboard
3. Navigate to Plugins > Add New > Upload Plugin
4. Choose the downloaded ZIP file
5. Click "Install Now"
6. Click "Activate Plugin"

MANUAL INSTALLATION (FTP)
1. Extract the ZIP file
2. Upload gym-multi-participant-booking/ folder to /wp-content/plugins/
3. Log in to WordPress dashboard
4. Navigate to Plugins
5. Find "Gym Multi-Participant Booking" and click "Activate"

CONFIGURATION
1. Ensure WooCommerce is installed and activated
2. Navigate to WooCommerce > Participant Booking
3. Configure your gym details:
   - Business name
   - Business email
   - Business phone
   - Business address
4. Configure email settings:
   - From name
   - From email
   - Subject line
5. Configure form settings:
   - Form title
   - Form description
   - Field labels
6. Save settings
7. Edit any product:
   - Go to Products > Edit Product
   - Click "Participants" tab
   - Check "Enable Participant Booking"
   - Set minimum/maximum participants
   - Save product
8. Test on frontend:
   - Add product to cart with quantity > 1
   - Fill participant details
   - Complete checkout
   - Check emails sent
